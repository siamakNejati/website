# Repository Instructions

These instructions apply to the entire repository.

- Inspect existing documentation, configuration, and conventions before editing.
- Preserve unrelated user work and make the smallest coherent change needed for the task.
- Never expose, commit, or copy credentials, tokens, private keys, or local environment files.
- Run validation appropriate to the files changed and report what was and was not verified.
- Confirm exact targets before bulk moves, overwrites, or deletions; prefer reversible operations.
- Follow any more specific `AGENTS.md` found in a subdirectory for files under that directory.
